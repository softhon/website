For most of 2023 and 2024, the default AI use case was the chat interface: a user asks a question, an LLM responds. Useful. Interesting. But fundamentally passive.

The shift happening now is different. **Agentic AI** — systems where an AI model can perceive context, make decisions, use tools, and take action — is a category change, not an incremental improvement.

## What Makes an Agent an Agent

A language model becomes an agent when it's given three things:

1. **A goal** — something it's trying to accomplish, not just answer
2. **Tools** — the ability to take actions (search the web, query a database, call an API, write a file)
3. **A feedback loop** — the output of one action informs the next

The result is a system that can handle multi-step workflows — things that previously required a human to coordinate across multiple tools and decision points.

## The Product Implications

For product teams, this isn't a marginal change. It means:

**Entire workflow categories become automatable.** Tasks that required human judgement at each step — because they involved synthesising information, making a decision, then acting — can now be handled by an agent operating within defined boundaries.

**The interface changes.** When users can express intent in natural language and have a system act on it, the question isn't "what button do we put here?" It's "what outcome does the user actually want, and how do we make that achievable in one step?"

**Trust and safety become design problems.** An agent that can take action needs guardrails — what can it do unilaterally, what needs confirmation, what should it never do? These are product decisions, not just engineering ones.

## Where We're Seeing the Most Impact

The highest-leverage agentic use cases we're seeing right now:

- **Internal operations** — agents that handle routine decisions, route requests, and maintain state across systems
- **Customer-facing automation** — support agents that can actually resolve issues, not just deflect them
- **Data synthesis** — agents that pull from multiple sources, reason over the results, and surface actionable insight
- **Software development** — AI-assisted coding, testing, and review that operates in the background

## The Build Consideration

Building agentic systems well requires rethinking evaluation. You can't just test inputs and outputs — you need to test *behaviour over sequences of actions*. This is genuinely harder, and it's where teams often underinvest.

Reliability, observability, and graceful failure are non-negotiable. An agent that silently does the wrong thing is worse than one that fails loudly.
